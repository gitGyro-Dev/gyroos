## 🧭 Overview

Gyro Logic is a novel logical framework where:

* Truth is not a fixed value
* Truth is observer-dependent
* Truth evolves with context and history

[

]

* Truth = point in manifold
* Conflict = curvature

* Logic = dynamic evolution
