# 07. Consciousness Layer

---

## 1. Overview

The Consciousness Layer is a meta-control mechanism that operates above the core execution loop.

It does not process representations directly.
It controls how the system observes and evaluates them.

---

## 2. Role

* Update Slice strategies
* Adjust deviation sensitivity
* Modify stability thresholds
* Guide Jump decisions

---

## 3. Position in Architecture

```text id="consciousness-position"
Core Engines:
  Slice → Δ → Stability → Selection → Jump

Meta Layer:
  Consciousness Layer
      ↓
  modifies Slice / Stability / Selection policies
```

---

## 4. Function

### 4.1 Slice Strategy Control

* Which slices to generate
* How many slices to maintain
* Resolution / abstraction level

---

### 4.2 Δ Sensitivity Control

* Which deviations matter
* Weighting of Δ components

---

### 4.3 Stability Adjustment

* Dynamic threshold tuning
* Context-aware tolerance

---

### 4.4 Jump Guidance

* When to allow reconfiguration
* Exploration vs stability balance

---

## 5. Characteristics

* Operates on policies, not data
* Works over time (long-term optimization)
* Optional in early implementation

---

## 6. Implementation Note

In v1:

* Simple rule-based policy layer

In v2+:

* Adaptive / learning-based meta-controller

---

## 7. Key Insight

The system does not just evolve states.

👉 It evolves how it observes states.

---

## 8. One-line Definition

The Consciousness Layer controls how the system chooses to observe and evaluate the world.
