# Gyro Logic Overview

Gyro Logic is a new formal system where:

- Meaning is behavior
- Truth is a slice of behavior
- Conflict is interference
- Logic is evolution

## Core Equation

\[
\frac{d\mathcal{B}}{dt}
=
\Phi(\mathcal{B})
-
\nabla \mathcal{L}_{stab}
+
\mathcal{I}(\mathcal{B})
\]

## Key Idea

Logic is not static.
It is dynamic, contextual, and evolving.
